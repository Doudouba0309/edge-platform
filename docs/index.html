Keeping this library current

  • This page is the authoritative index. Add new documents here when they become current.
  • Remove a document from this page when it is superseded; delete the file only when it has no historical value.
  • Keep the live version, test count and operational state tiles above in sync with the release checklist.
  • Run make check; tests/test_docs_index.py fails if a local link is broken.
  • Historical documents are labelled; they are not maintenance targets.
