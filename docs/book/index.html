How to read this book

If you are not technical

Read Parts 1, 2 and 7 in order. They explain the purpose, the shape and the current state without requiring you to run anything.

If you want to rebuild it

Read Parts 1 and 2 for context, then follow Parts 4 and 5 with a terminal open. Part 6 is the troubleshooting safety net.

What this book is not

  • It is not a production operations manual. The deployment is a sandbox proof.
  • It is not a claim that real factory devices are supported yet. The current source is synthetic.
  • It does not contain private keys, passwords or AWS secrets. Those stay on the machine, never in the repository.
The one-sentence version. We built a small, careful data pipeline for factory readings, packaged it as a Greengrass component, and proved that a reading can travel from the collector through the local postmaster into AWS IoT Core.
