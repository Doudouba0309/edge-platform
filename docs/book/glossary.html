Reference

Glossary

Every term that matters, in ordinary language. Use this page as a bookmark while reading the rest of the handbook.

A–C

TermPlain meaning
AdapterSoftware that speaks one factory protocol and turns its readings into the common Sample shape.
AgentAn AI worker that can perform a scoped task in the repository, with rules and verification gates.
ARM64 / aarch64The processor family used by many small gateways, including Apple Silicon and Raspberry Pi. Greengrass reports it as aarch64.
AWSAmazon Web Services, the cloud provider that hosts IoT Core, S3, IAM and Greengrass management.
BatchA group of samples from one device, sent as one message. Batching reduces cloud message cost.
Base component setThe shared northbound pieces: pipeline, spool, health, config loader and publisher.
Base imageThe prebuilt operating system and runtime that runs on the gateway. Only the bottom layer is an image.
Bounded queueA queue with a fixed maximum size. When full, the collector drops by policy rather than growing until the device runs out of memory.
CACertificate Authority. The Amazon root CA is the trusted starting point for the TLS certificate chain.
CertificateA digital identity document. The gateway uses its certificate to prove who it is to AWS.
CIContinuous Integration — automatic checks that run when code is pushed.
CollectorThe program that reads sources, batches samples and hands them to a sink. The main application in this repository.
ComponentAn installable Greengrass package: code, a recipe, a version and permissions. The collector is one component.
ContractThe agreed data shape and rules. Here: Sample, Batch, the JSON Schema, topics and identifiers.

D–I

TermPlain meaning
Device idThe logical asset a reading belongs to, for example plc-line-1. It is a topic level, not a physical serial number.
Direct IoT CoreA deployment where the collector itself connects to IoT Core with a client certificate, instead of going through the Greengrass nucleus. The MQTT sink can do this; it is not the preferred path.
Drop policyWhat to do when the memory queue is full: discard the oldest reading or the newest one. Counted, not silent.
EdgeThe place near the factory equipment, where the gateway lives. “Edge computing” means processing data there rather than only in the cloud.
FrozenDeliberately hard to change. A frozen contract can still be versioned, but not casually edited.
GatewayThe computer at the edge. It runs the collector and the Greengrass nucleus.
GreengrassAWS IoT Greengrass V2: the software that manages components, identity, secure connection and offline behaviour on the gateway.
Greengrass IPCInter-process communication over a local Unix socket. The collector uses it to ask the nucleus to publish to IoT Core.
Health endpointA tiny HTTP service: /healthz for liveness, /readyz for readiness, /stats for counters.
IAMAWS Identity and Access Management: users, roles and permissions.
ImageA prebuilt filesystem and runtime that can be booted as a container. The collector image is the base for the gateway.
IoT CoreThe AWS MQTT message broker and device registry. It receives the telemetry.
IoT policyA policy attached to a device certificate. It limits which client id may connect and which topics may be published or subscribed.
IPC access controlThe component configuration that says which local IPC operations and topics a component may use.

L–R

TermPlain meaning
mTLSMutual TLS: both sides present certificates. The gateway proves itself to AWS, and AWS proves itself to the gateway.
ModbusA common industrial protocol based on registers and coils. It is a Phase 1 source, not yet implemented.
NucleusThe core Greengrass process on the gateway. It starts components, owns the device certificate and talks to AWS.
NoContainerA Greengrass execution mode where the component runs as a normal process, not inside a nested Docker container.
OPC UAAn industrial protocol with a structured address space, quality codes and security. It is a Phase 1 source, not yet implemented.
Outbox / spoolA disk buffer that holds completed batches while the uplink is down. SQLite is used here.
PipelineThe component that accepts samples, groups them, builds batches and delivers them in order.
PLCProgrammable Logic Controller: the industrial computer that controls a machine or line.
Point mapA configuration document that maps device addresses and registers to metric names, units, scaling and deadbands. The central Phase 1 deliverable.
QualityWhether a sample is good, uncertain, bad or stale. Carried on the wire, never inferred.
RecipeThe Greengrass component instruction card: name, version, platform manifests, artifacts, lifecycle commands and configuration.
Role aliasAn AWS IoT alias that points to the TES role. The nucleus asks for credentials through it.

S–Z

TermPlain meaning
S3Amazon Simple Storage Service. Stores the component ZIP and other objects.
SBOMSoftware Bill of Materials: a machine-readable inventory of the packages inside an image.
Schema versionThe version of the wire contract. Currently 1.0.
Sequence numberA monotonic batch counter. It helps ordering and debugging; it is not a database key.
SinkThe transport that sends a batch: log, MQTT or Greengrass IPC.
SourceThe thing that produces samples: synthetic today; Modbus, OPC UA and MQTT in future.
SpoolSee outbox. A durable FIFO queue for batches.
SurrogateA simulated device used to test an adapter without real hardware.
TESToken Exchange Service. The nucleus uses the device certificate and role alias to get temporary AWS credentials.
ThingThe AWS IoT registry entry for a device. The gateway id is also the thing name.
Tier 1The two supported architectures: arm64 (aarch64) and x86_64 (amd64).
TopicThe MQTT address a message is published to, for example edge/gw/device/telemetry.
UTCCoordinated Universal Time. All timestamps on the wire are timezone-aware UTC.
WALSQLite’s Write-Ahead Log mode, used for crash-safe spooling.
WheelhouseA folder of pre-downloaded Python packages so the component can install offline.
Still uncertain about a term? Search the handbook for it, or read the “Design” part where the term first appears. The glossary is deliberately short; the chapters carry the nuance.
