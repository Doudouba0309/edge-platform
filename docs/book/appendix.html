Snapshot and provenance

This handbook describes the repository as of 17 October 2026, after the AWS sandbox proof. The code history at that point contained 21 commits; the latest code commit before this book was e4f425a (heartbeat drill and release checklist), following the 1.0.10 fixes. The book itself is a documentation change.

The AWS proof used component version 1.0.10, region ap-southeast-1, core architecture aarch64 and the synthetic source. The x86_64 image was exercised locally, not deployed to AWS.

If the sandbox is torn down later, this appendix remains a historical record. The rebuild chapter is the repeatable path; the resource inventory describes what the proof created.
